# 🌐 Labdhi Mandovara — Personal Portfolio

A modern, interactive portfolio website showcasing my work in **Artificial Intelligence, Software Engineering, Full-Stack Development, and Creative Design**.

Designed with a clean, warm aesthetic and smooth user interactions, the website highlights my projects, technical skills, experience, certifications, and creative work in a single responsive application.

## 🔗 Live Demo

**Portfolio:** https://labdhi-portfolio-pxen8hn3r-labdhi-mandovaras-projects.vercel.app

---

## ✨ Features

* Responsive design for desktop, tablet, and mobile
* Smooth animations powered by Framer Motion
* Interactive project showcase
* Skills section with categorized technologies
* Experience, certifications, and achievements timeline
* Creative artwork gallery
* Contact section with social links
* Easy content management through a single data file

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/Labdhimandovara/labdhi-portfolio.git
cd portfolio
```

### Install Dependencies

```bash
npm install
```

### Run the Development Server

```bash
npm run dev
```

Open:

```text
http://localhost:5173
```

---

## 📦 Build for Production

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

---

## ✏️ Customization

Most website content can be updated from:

```text
src/data/portfolioData.js
```

You can easily modify:

* Personal information
* Skills
* Projects
* Experience
* Certifications
* Social links
* Artwork gallery

To replace images:

1. Add the new image inside the appropriate `src/assets/` folder.
2. Update the corresponding import in `portfolioData.js`.
